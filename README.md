# Задания 25-ПРО-1

Веб-приложение группы 25-ПРО-1: все задания, лекции и файлы, отметки «сделано», личные заметки и кнопки «спросить нейросеть».

**Сайт:** https://rahatulyerbolat05-dotcom.github.io/zadaniya-25pro1/

## Как пользоваться
1. Открыть сайт → «Войти через Google».
2. Подождать, пока админ группы пустит (экран обновится сам).
3. Отмечать задания кружком, открывать материалы, жать «Помощь нейросети».

## Для админа
- Профиль → «Студенты и заявки»: пускать или закрывать доступ.
- Профиль → «Импорт заданий и файлов»: загрузить JSON (готовит Claude).
- На странице материала → «Изменить»: срок сдачи, описание, скрыть.

## Устройство
- `index.html`, `app.js`, `app.css` — собранный сайт (исходники у владельца, сборка esbuild).
- `firestore.rules` — правила доступа (копия того, что стоит в Firebase).
- Firebase: Authentication (Google) + Firestore, тариф Spark (бесплатно).

Подготовлен файл `updates/2026-11-17.json`: **27 карточек и 42 ссылок на учебные файлы**. Включены новые материалы практики, реферат по физкультуре до 19.11 и пропуски в сохранённом импорте от 25.10 (ИКТ, РО 1.2–1.6, этика и казахский). Личные блоки, журналы оценок и старые копии уже перенесённых материалов исключены. Вход администратора → Профиль → «Импорт заданий и файлов» → выбрать JSON → импортировать. Публикация файла в репозитории сама по себе не записывает карточки в Firestore.

Поле импорта `appendSubjects` добавляет новые предметы, сохраняя существующие записи и их настройки. В одном импорте нельзя одновременно использовать `subjects` (полная замена списка) и `appendSubjects` (добавление). Повторный импорт тех же ID обновляет материалы и не создаёт дублей. Личные отметки выполнения не затрагиваются.

Импорт по ссылке: в админском разделе можно вставить HTTPS-ссылку на JSON с этого же сайта, загрузить предпросмотр и нажать «Импортировать». Внешние адреса, перенаправления, повреждённые JSON и файлы больше 8 МБ отклоняются. Проверки доступа к базе остаются прежними.

Объявления: материалы с `type: "announcement"` и `hasTask: false` показываются отдельным блоком на главной странице, три последних по дате. Они не увеличивают число заданий. Объявления используют обычный админский импорт и действующие права доступа.

Учебная практика ПМ 01 выделена отдельным блоком в списке предметов и заданий. Карточка `pm-01-practice-01` содержит выданную 17.11 ПР № 1, DOCX и архив задания 6. Старые РО остаются в своих предметах; новый раздел использует уже существующий ID, без повторного создания.

Исправление границ импорта: семь материалов, уже находившихся в личной коллекции администратора, исключены из общего пакета и текущих публичных файлов. Пакет `updates/2026-11-17-restore-private.json` скрывает ошибочно созданные общие копии и очищает их текст и ссылки; оригиналы в `private/*` не изменяет.
