# Задания 25-ПРО-1

Веб-приложение группы 25-ПРО-1: все задания, лекции и файлы, отметки «сделано», личные заметки и кнопки «спросить нейросеть».

**Сайт:** https://rahatulyerbolat05-dotcom.github.io/zadaniya-25pro1/

## Как пользоваться
1. Открыть сайт → «Войти через Google».
2. Подождать, пока админ группы пустит (экран обновится сам).
3. Отмечать задания кружком, открывать материалы, жать «Помощь нейросети».

## Для админа
- Профиль → «Студенты и заявки»: пускать или закрывать доступ.
- Профиль → «Импорт заданий и файлов»: загрузить JSON (готовит Claude).
- На странице материала → «Изменить»: срок сдачи, описание, скрыть.

## Устройство
- `index.html`, `app.js`, `app.css` — собранный сайт (исходники у владельца, сборка esbuild).
- `firestore.rules` — правила доступа (копия того, что стоит в Firebase).
- Firebase: Authentication (Google) + Firestore, тариф Spark (бесплатно).
